# Contributing

Thanks for improving UI Unslop. File a clear issue describing the real interface problem, or open a focused pull request with a rationale and before/after explanation. Favor actionable, framework-agnostic design guidance over aesthetic absolutes.

Before submitting, run:

```bash
python3 -m unittest discover -s tests -v
```

Keep `skills/ui-unslop/SKILL.md` concise and put detailed examples in `references/`. Preserve the 20 video-derived principle names, explain intentional exceptions, and avoid recommending changes that reduce accessibility, functionality or content truthfulness.

Do not include private code, credentials, confidential screenshots, or the original video/audio without appropriate rights. Contributions are made under this repository's MIT License.
