# Security policy

UI Unslop is a local instruction-based skill and installer; it does not require API keys, collect analytics, or call external endpoints. The installer copies only bundled skill files to selected local directories.

Treat all contributed skills and changes as executable instructions to an AI agent: review them before installing, particularly changes involving shell commands, network access or access to private files. Run skills with the minimum permissions needed. Never paste credentials into issues.

To report a potential vulnerability, use a private GitHub vulnerability report if enabled on the published repository. Otherwise contact the repository maintainer privately before public disclosure.
